# Shopify WOG

## Estructura

- `themes/dawn/`: código y configuración del tema Dawn.
- `docs/`: documentación del proyecto.
- `shopify-theme.sh`: acceso seguro a Shopify mediante Theme Access.

## Comandos

```bash
./shopify-theme.sh pull
./shopify-theme.sh dev
./shopify-theme.sh list
./shopify-theme.sh push
```

`push` actualiza directamente el tema Dawn configurado en la tienda de desarrollo.
